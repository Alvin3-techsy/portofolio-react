# Personal Portfolio React

Personal Portfolio yang dibuat menggunakan React, Vite, Bootstrap 5.3.3, dan React Router DOM.

## Teknologi
- React 
- Vite
- Bootstrap
- React Router DOM

## Cara menjalankan proyek



## Halaman
- `/` - Home
- `/about` - About
- `/projects` - Projects
- `/contact` - Contact

Navigasi halaman menggunakan React Router DOM. Bootstrap digunakan untuk desain, grid, tombol, form, navbar.
